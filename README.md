# 🤖 sAI-GPT Chatbot

## Project Description

sAI-GPT is a simple rule-based chatbot developed using Python.

It responds to predefined user commands using if-elif statements.

---

## Features

- Welcome Screen
- Current Date & Time
- User Name Input
- Help Menu
- About Section
- Continuous Chat
- Exit Command

---

## Technologies Used

- Python 3
- datetime module
